# Music

This folder is empty in the repository on purpose. The game runs without music; with the
files below in place, it plays them (the menus, the selection and the moves editor, and
the battles, each group rotating at random).

The tracks are Pokémon arrangements by **The Noble Demon**
(https://www.youtube.com/@TheNobleDemon), used with credit as the artist permits. They are
not redistributed here: the artist asks not to reupload the audio on its own. The released
builds of PokeBrawl carry them inside the game's package only. Original compositions by
Junichi Masuda and Go Ichinose.
